# Подготовленные данные стажировки «Технологии искусственного интеллекта при обработке геодезических и гравиметрических данных»

Данные для блокнотов стажировки по территории примера (окрестности Красноярска) и 70 территориям из документа «Темы ИАР и выбор индивидуальной темы». Блокноты скачивают их автоматически по адресу

```
https://raw.githubusercontent.com/tester170/geoai-internship-data/main/<папка>/<ключ>.<расширение>
```

Ключ – границы участка `ROI_BOUNDS` (запад, юг, восток, север) с двумя знаками после запятой, например `92.75_55.87_93.07_56.05`. Если для участка файла нет (собственная территория слушателя), блокнот получает данные из исходных сервисов.

| Папка | Содержимое | Исходный сервис |
|---|---|---|
| `icesat2/` | сегменты ICESat-2 ATL08 длиной 100 м за 2018-10-14 – 2025-12-31 (таблица parquet) | SlideRule (NASA) |
| `ggmplus/` | возмущения силы тяжести `dg`, мГал, и высоты квазигеоида `geoid`, м, модели GGMplus с шагом 0,002° вокруг участка с запасом 0,1° (архив NumPy npz: `dg`, `geoid`, `lons`, `lats`) | Curtin University |
| `photons/` | фотоны ATL03 с классами ATL08 на отрезке трека для рисунка второй недели (таблица parquet) | SlideRule (NASA) |
| `index.csv` | номер темы, территория, границы, ключ, число сегментов ICESat-2 | – |

Данные получены теми же функциями и с теми же параметрами, что используются в блокнотах.

**Источники и лицензии.** ICESat-2 ATL03/ATL08 – NASA National Snow and Ice Data Center DAAC, данные открытые; обработка – сервис SlideRule (University of Washington, NASA GSFC). GGMplus – Hirt C. и др., Curtin University, Western Australian Geodesy Group (https://ddfe.curtin.edu.au/models/GGMplus/). Данные приведены для учебных целей; при использовании указывайте исходные источники.
